# КМНС Монитор — документация и стратегия

## Установка

```bash
pip install -r requirements.txt
```

## Первый запуск

```bash
python kmns_monitor.py
```

При первом запуске все найденные документы будут помечены как новые.
При каждом следующем запуске — только действительно новые.

---

## Что мониторит и зачем

### 📜 pravo.gov.ru — принятые НПА
**Что:** Федеральные законы, указы Президента, постановления и
распоряжения Правительства после подписания.
**Зачем:** Финальная фиксация позиции государства. Если документ
здесь — он уже сила. Полезно для анализа и цитирования.
**Задержка:** Публикуется в день подписания или на следующий день.

### 🏛️ sozd.duma.gov.ru — СОЗД Госдума
**Что:** Все законопроекты — от первого внесения до подписания.
Показывает кто внёс, в каком чтении, голосование, историю.
**Зачем:** Самый важный источник для ОТСЛЕЖИВАНИЯ. Позволяет
увидеть законопроект до его принятия — есть время среагировать.
Фиксируй кто вносит законопроекты по КМНС-тематике.
**Задержка:** Практически в реальном времени.

### 📋 regulation.gov.ru — проекты до Думы
**Что:** Проекты нормативных актов на стадии разработки и ОРВ
(оценка регулирующего воздействия). Часто тут появляются
поправки к Закону об ООПТ, об охоте, о недрах.
**Зачем:** САМАЯ РАННЯЯ стадия — можно подать официальные
замечания в рамках публичных консультаций. Критично для
подачи позиции о FPIC до того как проект "закостенел".
**Ключевой флаг:** "📢 ОТКРЫТО ДЛЯ ЗАМЕЧАНИЙ"

### 🏢 fadn.gov.ru — ФАДН
**Что:** Новости, документы, планы, отчёты Федерального
агентства по делам национальностей.
**Зачем:** Понять позицию самого регулятора. Иногда выходят планы поддержки, которые
потом становятся основой для НПА.

## Команды

```bash
# Стандартный запуск (30 дней, только новые)
python kmns_monitor.py

# Глубокий поиск — первый раз или раз в квартал
python kmns_monitor.py --days 180

# Только конкретные источники
python kmns_monitor.py --source sozd regulation

# Добавить свои ключевые слова
python kmns_monitor.py --keywords "ТТП" "родовые угодья" "Чукотка КМНС"

# Все ключевые слова (~40 штук, медленнее, но полнее)
python kmns_monitor.py --full --days 60

# Показать всё (не только новое)
python kmns_monitor.py --all --days 7

# Только СОЗД, только JSON
python kmns_monitor.py --source sozd --format json
```

## Автоматизация

### macOS/Linux (crontab)
```bash
crontab -e
# Запускать каждый понедельник в 8:00
0 8 * * 1 cd /path/to/kmns_monitor && python kmns_monitor.py --quiet
```

### Windows (Планировщик задач)
Создай задачу через Task Scheduler: python.exe путь\kmns_monitor.py

## Выходные файлы

```
kmns_output/
├── kmns_20240520_0830.csv        ← все результаты (Excel-совместимо)
├── kmns_20240520_0830.json       ← структурированные данные
└── дайджест_20240520_0830.txt    ← читаемый текстовый отчёт
kmns_state.json                   ← память между запусками
kmns_monitor.log                  ← лог работы
```

**CSV** удобен для фильтрации в Excel/LibreOffice:
- Сортируй по колонке "новый" — "ДА" наверх
- Фильтруй по "тип" — законопроекты отдельно от принятых
- Ищи по "заголовок" — свои ключевые понятия

**JSON** нужен если хочешь дальше обрабатывать данные
(например, строить хронологию, импортировать в базу данных,
или передавать в другой скрипт).

## Стратегия использования

### Ежедневный workflow
1. Запустить `python kmns_monitor.py`
2. Открыть `дайджест_*.txt`
3. Обращать внимание на:
   - ⚡ СРОЧНО — законопроект на финальной стадии
   - 📢 ОТКРЫТО ДЛЯ ЗАМЕЧАНИЙ — нужно подать позицию
   - ★ НОВЫЙ с regulation.gov.ru — самая ранняя стадия

### Что искать в СОЗД
- Кто вносит: Правительство РФ / Минприроды / ФАДН / депутаты
- Статус: "внесён" → "первое чтение" → "второе чтение" → "принят"
- Дата третьего чтения = дедлайн для реакции

### Ключевые сигналы тревоги
- Поправки к ФЗ "О недрах" без упоминания КМНС
- Поправки к Лесному/Водному кодексу без ТТП-исключений
- Любые изменения в ФЗ-49 "О территориях традиционного природопользования"
- Изменения в ФЗ "О гарантиях прав малочисленных народов"
- Постановления о лицензировании в Арктической зоне

### Для ESG-анализа (Substack, IRMA/CMSI)
- Фиксируй: нарушают ли новые НПА процедуру консультаций
- Отслеживай: есть ли ОВОС/СПЭО упоминания в regulation.gov.ru
- Документируй: разрыв между декларациями ФАДН и реальными НПА

## Расширение инструмента

Можно добавить:
- `Telegram-бот` — мгновенные уведомления о новых документах
- `Росприроднадзор` (rpn.gov.ru) — экологические разрешения
- `Минприроды` (mnr.gov.ru) — профильный регулятор
- `Роснедра` — лицензирование в КМНС-регионах
- `Арктический совет` — международный уровень
- `Конституционный суд` — решения по КМНС-жалобам
